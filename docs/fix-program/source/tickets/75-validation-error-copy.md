# 票 75 — 长度超限校验错误文案不指明上限（S4，源：票 14 独立复验 F3；可并入 S4 批）

## 事实（独立验收 agent 实测）
Tracker 自备问题提交 5000 字符（上限 4000）被后端 400 拦截，但前端只弹
通用英文 “One or more validation errors occurred.”，不指明哪个字段、超了
多少上限。用户无从知道改到多短才合法。

## 任务
1. 先盘点：全站表单提交的服务端字段级错误呈现现状（票 12 已给 Knowledge
   弹窗做了字段级错误映射 applyServerError——以其为口径参照），列出哪些
   表单已字段级呈现、哪些仍是通用弹框。盘点表入证据。
2. 本票范围先行修 Tracker 自备问题（及盘点中同型的 Jobs 表单字段，如协调者
   确认）：字段级错误落到对应输入框下方，文案含上限数字，走 i18n 三语。
3. 盘点中其他服务的同型问题只列表报协调者，不在本票扩大修复。

## 验收
- 超限提交时对应字段下出现含上限数字的三语文案（按当前 locale），
  无通用英文弹框；其他校验错误（空值等）呈现不回退。
- tsc 通过；§7：错误映射纯逻辑若有改动带单测或 helper 冒烟校验（注明口径）。
