# 票 81 — Knowledge 分类名保存失败被 UI 吞掉 + 乐观显示假象（票 16 独立复验发现）

严重度：S2（保存失败静默 + 假成功显示，刷新即丢）
来源：票 16 独立真人化复验 D1（evidence-16/independent-acceptance.md，截图 ind-19/ind-20）。

## 复现
Tech Stack 分类管理器输入 200 字符分类名点 Add → 后端 PUT 返回 400（长度拦截正确），但管理器当场仍把该名显示在列表中、无任何可见错误提示；刷新后消失（未落库）。用户会以为已保存。

## 期望
- 保存失败必须有可见反馈（snackbar 错误提示，对齐全站先例），且不得乐观显示未落库的名字（或失败后回滚显示）。
- §7：若抽出校验/错误处理纯函数须带单测含 boundary（上限±1、空、Unicode）。
- §8 影响面：Tech Stack 分类管理路径；不变项 = 后端 400 拦截本身不动、正常保存流程不变。
