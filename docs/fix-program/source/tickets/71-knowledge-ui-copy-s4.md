1. **英文界面混入中文**：切到英文 locale 时，Knowledge 页面仍直出中文
   「复习热力图 / 少 / 多」（热力图区）与「口语练习」——疑似组件内硬编码
   中文字符串未走 i18n。修法：补三语 i18n 键并改走词典（与票 13 FUN-06
   的补键口径一致）；顺手 grep Knowledge 功能区其他硬编码中文，一并列清单，
   本票范围内的一并修，范围外的报协调者。
2. **必填标签双星号**：新建弹窗必填字段标签出现「**」（模板星号 + 词典
   文案自带星号叠加）。修法：去重为单星号，口径与全站其他弹窗一致
   （先核查其他弹窗是模板加星还是词典加星，统一到既有多数口径）。
3. **空块占位文案与实际不符**：某空态占位文案称 Edit 按钮在「top-right」，
   与详情卡内实际位置不符。修法：文案改到与实际布局一致（改文案不挪按钮；
   若三语文案都涉及，一并对齐）。
