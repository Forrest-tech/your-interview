# 票 78 — STAR 故事保存快速连点触发并发 upsert 竞态 500（S3，源：票 15 独立复验 D2/F2）

## 复现（独立验收 agent 实测，2/2 稳定，evidence-15/independent-acceptance.md D2 节）
新建故事表单填好后对保存按钮双击+连点：保存走
`PUT /api/interviews/star-stories/<时间戳 clientId>`（upsert 语义），
两发并发 PUT 同一 clientId——第一发 200，第二发 **500**，
响应体 DbUpdateException / Postgres 23505 唯一约束冲突。
用户侧净结果无损（只新增 1 条、无重复、无可见报错），但服务端 500 属实。

## 任务（二选一或组合，报告中注明取舍）

  或捕获唯一冲突后回读返回成功结果，使并发同 clientId 双写都得 2xx
  且最终只存一份、内容为后写值（与现行 last-write-wins 口径一致）。
- 前端：保存按钮提交期间禁用/防重复提交（与全站表单防重口径对齐，
  先盘点既有先例再落）。
- 注意同型面：legacy import 的打标已防重复发起，但服务端幂等同样应
  经得起并发双发——顺手核查并在报告中给出结论（修或不修及理由）。
