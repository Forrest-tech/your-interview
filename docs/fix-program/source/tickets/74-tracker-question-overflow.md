# 票 74 — Tracker 自备问题超长无空格文本横向溢出（S3 呈现，源：票 14 独立复验 F2）

## 复现（独立验收 agent 实测，evidence-14/independent-acceptance.md）
投递详情 Questions 页签添加一条 2000–4000 字符、无空格的连续长文本问题：
保存成功、数据无损，但列表项不换行，横向溢出并顶移抽屉内其他内容。

## 任务
- Questions 列表项文本加换行约束（overflow-wrap:anywhere / word-break
  口径按组件既有样式惯例），使任意长文本在抽屉宽度内换行显示。
- 顺手核查同一抽屉内其他长文本呈现（问题删除/编号列布局在长文本下不被
  顶移）；范围仅限 Questions 页签呈现，不动其他页签。

## 验收
- 4000 字符无空格问题在页签内正常换行、无横向滚动、抽屉布局不错位
  （截图对照）；含空格的普通长文本、短文本呈现不回退。
- tsc 通过；数据读写行为不变（纯 CSS/模板呈现层）。
