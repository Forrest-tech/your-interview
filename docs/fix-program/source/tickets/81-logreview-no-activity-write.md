# 票 81 — Log review 不写复习活动、热力图永不据实着色（S2，源：票 16 第二道独立复验 F1）

## 事实（evidence-16/independent-acceptance.md 续写节，T2）
Tech Stack 对条目 Log review：复习计数 0→1→2、刷新保持（计数链正常），
但热力图当日格恒不着色；服务端旁证：该账号 GET review-activity = []，
即 **Log review 根本不写 review-activity**，活动流未接线。对照：经导入
路径写入的活动在热力图正确着色——渲染无问题，缺的是真实复习行为的写入。

## 任务
- 定位缺失点（前端 log-review 动作未调活动 record，或后端条目复习
  handler 未落活动行——读码定责，只改缺失一侧，不两边都改）。
- 写入的日期/合并口径与票 16 已落地的 record/导入端点既有口径一致
  （同日合并规则照既有实现，勿另立口径）。
- 若动后端 handler 纯逻辑，带 §7 单测（含 boundary：同日多次、同日与
  导入同日叠加、跨日、空账号）。

## 验收
- 界面 Log review 后：热力图当日格着色 + GET review-activity 旁证有
  当日记录；刷新保持；跨日/同日口径与导入一致（活体证据落盘）。
- §8 影响面：复习计数链、导入路径、热力图渲染均回归；不变项：计数
  自增口径、导入防重口径不动。
- 完成后票 16 的 T2 场景由协调者安排复验。
