# 55: 陈旧测试裁决修复（AttachAssetValidator_MissingRoundId_Invalid）

**来源：** 票 01 验收时发现的票面外问题（基线即失败，非任何修复引入）
**严重度：** S4（测试口径）
**区域：** Services.Interviews.Tests
**Blocked by:** None (can start immediately)
**Status:** ready-for-agent

## What to build

`AssetRoundPhaseTests.AttachAssetValidator_MissingRoundId_Invalid` 断言「缺 RoundId 应校验失败」，但 `AttachAssetCommandValidator` 自始无 RoundId 规则——RoundId 可空是**有意设计**：条目级材料（截图、整场转写等不属于某一轮的材料）靠 EntryId 挂载，是已上线的统一入口/材料功能所依赖的行为。协调者裁决（2026-10-21）：**改测试，不动校验器**。

把该用例改为断言现行正确口径：缺 RoundId（但 EntryId/FileName/Kind 合法）时校验**通过**，并更名为 `AttachAssetValidator_EntryLevelWithoutRoundId_Valid`；如需保留「必填项缺失应失败」的覆盖，另加一条针对 EntryId 为空的用例。
