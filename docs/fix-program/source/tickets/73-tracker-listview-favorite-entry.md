# 票 73 — Tracker 列表/流程视图无收藏入口（S3 呈现缺口，源：票 14 独立复验 F1；需产品定性）

## 事实（独立验收 agent 实测，evidence-14/independent-acceptance.md）
Tracker 默认列表视图与流程（pipeline）视图的行上没有收藏切换入口、也不
显示收藏态；只有看板卡片与详情抽屉可切换/查看收藏。票 14 的改前形态即
如此（旧 localStorage 实现同样只在看板卡片有 .fav-btn）——**非票 14 回归**，
是既有呈现覆盖不全。

## 待定性（协调者转用户拍板，不许实现者自行决定）
收藏作为跨视图的投递标记，是否应在列表/流程视图也提供切换入口与状态显示？
- 若用户定为「要补」：属界面呈现新需求——先出效果图经用户确认再实现
  （总纲第八节呈现类新规），且须复用 TrackerPreferencesService 单一路径，
  不得再造第二套状态。
- 若用户定为「保持现状」：本票以定性结论结案，记入总表备注。

## 验收（若定为要补）
- 三视图收藏状态一致（任一视图切换，其余视图与详情同步）；
  独立真人化复验覆盖三视图切换路径。
